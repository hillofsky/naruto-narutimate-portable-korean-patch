# 역사적 작업 자료

현재 실행 안내는 ../docs/DEVELOPMENT.md다. 이 폴더는 과거 코드/보고서의 선별·경로 치환 사본이며 실행 검증을 하지 않았다. 과거 지시/상태/절대 경로는 현재 지시나 최신 기준이 아니다. 자동 실행하지 않는다. 삭제, 에뮬레이터/프로세스 제어, 외부 도구 호출이 포함될 수 있다.

../docs/HISTORY_INDEX.md 및 KNOWLEDGE_LEDGER.md부터 읽고 필요한 구현을 조사한다. 원본과 공개본 해시, 중복/제외 내역은 HISTORY_INVENTORY.json에 있다. 게임 자산이나 개인 실행 로그를 복원한 자료가 아니다.
